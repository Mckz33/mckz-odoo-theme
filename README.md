# MckZ Odoo Theme

Modern backend theme for Odoo 18 with sidebar navigation and customizable design.

## Modules

### mckz_web_enterprise_theme
Main theme module that provides:
- Modern UI design with customizable colors
- Font customization support
- Border radius and density settings
- Dark mode support

### mckz_web_appsbar
Sidebar navigation module:
- Toggle sidebar with app menu
- Submenu hover navigation
- User menu with profile, settings, logout
- Keyboard shortcuts (ESC to close)
- Responsive design

### mckz_web_colors
Color scheme management:
- Light and dark mode color schemes
- Customizable brand colors
- Settings page integration

### mckz_web_chatter
Enhanced chatter/messaging component

### mckz_web_dialog
Custom dialog/modal styling

## Installation

1. Copy all modules to your Odoo addons directory
2. Update the apps list
3. Install `mckz_web_enterprise_theme` (it will install dependencies automatically)

## Requirements

- Odoo 18.0
- Python 3.10+
